# 開発者向け仕様書

## 1. 概要

本システムは、サッカープレミアリーグの複数のチームに関する情報を一覧表示し、詳細閲覧、新規登録、編集、削除を行うことができる Web アプリケーションである。  
Express（Node.js）と EJS を用いて実装し、データはメモリ配列で管理している。今後はデータベース連携に拡張可能な構造を持つ。

---

## 2. 使用技術

| 分類 | 内容 |
|-------|-----------|
| サーバーサイド | Node.js / Express |
| テンプレートエンジン | EJS |
| ビュー構造 | HTML + EJS |
| データ保存 | JavaScript 配列（擬似DB） |
| ポート番号 | 8080 |

---

## 3. 目的

- サッカープレミアリーグのチーム情報を Web 上で管理できるようにする
-チーム情報を CRUD 操作（Create / Read / Update / Delete）で扱えるようにする
- Web アプリ開発の基礎（HTTP と REST、画面遷移、フォーム処理、テンプレート）の理解

---

## 4. 機能一覧

| 機能 | 内容 |
|-------|------|
| チーム一覧表示 | チーム情報を一覧形式で表示 |
| チーム詳細表示 | 選択されたチームの個別情報を表示 |
| 新規登録 | チーム情報の追加（フォーム入力） |
| 編集 | 既存チームの情報を変更 |
| 削除 | チーム情報を削除 |
| ページ遷移 | リンクまたはボタンで各機能に移動 |

---
